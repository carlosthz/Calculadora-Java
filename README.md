# 🧮 Calculadora em Java

Projeto desenvolvido em Java com foco no fortalecimento da lógica de programação, Programação Orientada a Objetos (POO), tratamento de exceções e organização de código.

## Funcionalidades

* Soma
* Subtração
* Multiplicação
* Divisão com tratamento de exceções
* Validação de entradas

## Tecnologias Utilizadas

* Java
* Eclipse IDE
* Git
* GitHub

## Objetivo

Este projeto foi criado como parte da minha evolução prática em Java, com foco no desenvolvimento de fundamentos sólidos em lógica de programação, estruturação de sistemas e boas práticas iniciais de desenvolvimento.

## Aprendizados

Durante o desenvolvimento deste projeto, pratiquei conceitos importantes como:

* Métodos
* Estruturas condicionais
* Tratamento de exceções
* Organização de código
* Entrada e validação de dados
* Programação Orientada a Objetos
